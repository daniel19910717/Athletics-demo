# iOS Base Application
This project contains the base application upon which the iOS take-home interview will be implemented.

## Application Design
This application:
* is meant to run as a simple, standalone app that connects to a lightweight REST backend
* is 100% Swift, uses Async/Await, SwiftUI, and Combine
* is implemented with an MVVM architecture
* is incomplete! (see next section)

## Take Home Interview
This project is a starting point for interview candidates to display technical skills and design creativity.

As such, it may contain:
* incomplete experiences or features
* bugs
* broken patterns
* leaks or inefficiencies
